# US G003 - As Project Manager, I want the team to use the defined project repository and continuous integration server.


## 1. Context

This US was assigned to us because it is necessary to have a git repository to be able to have a method of file sharing between the team members and a way to share the work with the teachers. The night builds are necessary to control that our project is always buildable.

## 2. Requirements

The team should accept the assigned GitHub repository and set it up to be used along the project.
The GitHub repository will provide night builds with the publishing of results and metrics.

## 3. Analysis

We received the invite so that we could set up the repository.

## 4. Design

### 4.1. Realization
The first team member set up the repository and the others joined the repository.
The night builds were already set up so we didn't have to do anything in that regard.

### 4.2. Tests
